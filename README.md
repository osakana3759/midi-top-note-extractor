# MIDI Top Note Extractor

MIDIの各トラックから、**同時に鳴っている音のうち最も高い音だけを残す**ブラウザツールです。
ファイルはすべてブラウザ内で処理され、サーバーには送信されません。

Keep only the highest note at each moment in your MIDI tracks, right in your browser. No upload, no install.

**https://osakana3759.github.io/midi-top-note-extractor/**

## 特徴

- 和音やコードを含むトラックから、最高音のラインだけを取り出せる
- トラックごとに処理するかどうかを選べる
- 処理しないトラックは「そのまま残す」か「削除する」かを選べる
- 処理前後のノート数を表示
- 端末内で完結（外部送信なし）・元のファイルは変更されない

## 使い方

1. MIDIファイル（`.mid` / `.midi`）をドロップ、またはクリックして選択
2. 処理するトラックにチェックを入れる
3. 「選択していないトラックを残す」のON/OFFを選ぶ
4. 「最高音だけ残してMIDIを書き出す」を押すと、`元のファイル名_cleaned.mid` がダウンロードされる

読み込んだファイルは、右の ✕ ボタンで取り消せます。

## 処理の仕組み

トラック内のノートの開始・終了位置で時間を区切り、各区間で鳴っている音のうち最も高い音だけを残します。

- 重なりの途中でより高い音が始まった場合、低い音はその区間だけ分割・削除されます。
- 高い音が終わったあとに低い音が続いている場合は、残りの部分を復元します。
- 同じ高さの音が重なっている場合は、先に始まった音を優先します。
- ノートオフが見つからないノートオンは、長さが分からないため無視します。

### 未選択トラックを削除する場合

出力からトラックを削除すると、テンポ・拍子・調号を持つトラック（format 1のコンダクタートラックなど）まで消えてしまうことがあります。
これを防ぐため、削除するトラックにだけこれらの情報があるときは、最初の出力トラックに移して保持します。

## 対応形式

- Standard MIDI File format 0 / 1
- 時間分解能は PPQ（四分音符あたりのtick数）のみ

次の形式には対応していません。

- SMF format 2
- SMPTE 形式の時間分解能

## ローカルで動かす

ES Modules を使っているため、`index.html` をダブルクリックして開くのではなく、簡易サーバー経由で開いてください。

```bash
npx serve .
# または
python -m http.server
```

その後、表示されたURL（例：`http://localhost:3000`）をブラウザで開きます。
